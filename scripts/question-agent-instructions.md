# 408 真题数据全量扩充规范 v2（数据代理必读，全部读完再动手）

## 任务背景

现有题库是"每年 16 题"的抽样版（`src/data/questions/y{年}.ts`，答案已经核对，称为**种子题**）。
目标：扩充为真实卷面**全量**——每年 47 题（40 单选 + 7 综合应用），2009-2026 共 18 年 846 题。
种子题必须**原样保留**（id、题干、选项、答案、解析、分值都不改），按其卷面题号 no 并入新结构，再补齐其余题目。

## 真实卷面结构（每年固定，不得变动）

- 单项选择题 40 题：卷面题号 1-40，每题 2 分，共 80 分
- 综合应用题 7 题：卷面题号 41-47，合计 70 分；41-42 数据结构、43-44 计组、45-46 操统、47 计网
- 总分 150 分
- 单选科目分布（标准；个别年份可能有 ±1 题出入，以种子题的 no 反推该年真实区间为准）：
  1-11 ds（数据结构）、12-22 co（计组）、23-32 os（操统）、33-40 cn（计网）

## 产出文件（只写这 4 个文件，不要动其他任何文件）

目录 `src/data/questions/y{年}/`（年份替换，如 y2009/）：

| 文件 | 内容 | 导出名 |
|---|---|---|
| mc1.ts | 卷面题号 1-20 的单选 | `export const mc{年}Part1: Question[]` |
| mc2.ts | 卷面题号 21-40 的单选 | `export const mc{年}Part2: Question[]` |
| comp.ts | 卷面题号 41-47 的综合题 | `export const comp{年}: Question[]` |

index.ts 固定写法（年份替换）：

```ts
import type { Question } from "../types";
import { mc2009Part1 } from "./mc1";
import { mc2009Part2 } from "./mc2";
import { comp2009 } from "./comp";

/**
 * 2009 年考研 408 真题 · 全量版（47 题 = 40 单选 + 7 综合应用）

 */
export const questions: Question[] = [...mc2009Part1, ...mc2009Part2, ...comp2009].sort(
  (a, b) => (a.no ?? 0) - (b.no ?? 0),
);
```

**每写完一个文件立即保存，再写下一个**（防止超时导致全部丢失）。若目录中已有文件（重试场景），先读已有内容，只补缺失/修正错误的部分。

## 字段规则

1. **id**：`"{年}-{科目}-{两位序号}"`，科目内连续编号。种子题保留原 id；新题从该科目已有最大序号 +1 继续（如 2009 年 ds 已有 ds-01..ds-05，新 ds 题从 ds-06 编起）。id 序号与卷面题号 no 无需对应，id 只是唯一键。
2. **no**：卷面真实题号，**必填**；47 个题号 1-47 不重不漏，no 与科目必须匹配（如 no=35 应是 cn）。
3. **type/score**：单选 `"single"`、score 恒为 2；综合题 `"application"`。综合题分值优先沿用种子题分值，其余按真实试卷（可搜索核对）；完全不确定时用默认 41:13、42:10、43:13、44:10、45:8、46:7、47:9，但**全年 7 道综合题分值合计必须 = 70**（种子分值导致不足/超出时，合理调整新增综合题分值凑足 70）。
4. **difficulty**：只能是 `1 | 2 | 3`（写 4、5 会编译错误）。
5. **options/answer**：单选恰好 4 项、不带 "A." 前缀，answer 为 "A"/"B"/"C"/"D"；综合题 options 为 `[]`，answer 为完整参考答案（Markdown，按小问 （1）（2）（3） 分点，含解题步骤）。
6. **analysis**：单选每题 ≥80 字（为何对 + 干扰项为何错）；综合题 ≥150 字（思路点拨 + 评分要点，参考种子题写法）。
7. **tags**：每题 2-4 个知识点。

## 内容真实性（核心要求）

- 种子题已核对，**不要改动**。
- 新增题以还原**该年真题原题**为目标：题号即线索（科目 + 该年考点范围）。凭你对历年 408 真题的了解尽力还原题干、数据与选项。
- **答案必须正确**，写入前逐题推演验证。
- 原题附图的（二叉树、图、电路、网络拓扑等）：改为精确文字描述（括号表示法、边表、参数表格），或替换为同年同科目可文字化的真题/忠实改编题，难度保持一致。绝不引用图片。
- 答案或分值不确定时可用 web-search 搜"{年}年考研408真题及答案"核对，**最多 3 次搜索**，禁止大量浏览网页（防超时）。2026 年例外：网上暂无完整资料（已确认过），全部按回忆版/改编题生成，不要搜索。
- 实在无法还原的题：按王道/天勤教辅风格编写**同难度替版**，考点必须落在该年该科目大纲内。绝不留空、绝不跳过题号。
- 每年必须凑满：单选恰好 40 题（no 1-40 不重不漏）、综合恰好 7 题（no 41-47）。

## Markdown / TypeScript 规范（防编译与渲染错误）

- 所有字符串用反引号模板字符串；内容中的反引号写成 \\`，`${` 写成 \\${
- 代码用围栏代码块（\\`\\`\\`c 等）、行内代码用反引号；表格用 GFM 管道表格
- 数学纯文本：2^10、log2n、(x+1) mod 8、×、÷、≤、≥、Ω(n)；**禁止 LaTeX（$...$）、禁止 HTML 标签、禁止图片**
